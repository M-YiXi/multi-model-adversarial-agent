# 多模三维对抗思维引擎（包含辅助模型的多维对抗智能体）

> **实验版本 · Experimental Version**

## 项目简介

**多模三维对抗思维引擎**（Multi-Model 3D Adversarial Thinking Engine）是一个基于**温度分层 + 异质对抗 + 全局收敛**原理的科研级问题求解系统。

核心思想是通过拆解大模型认知能力，利用多个不同角色、不同厂商的模型在受控条件下的对抗式协作，突破单模型的**认知茧房**、**思维固化**与**对齐偏差**问题，主攻大型工程 / 科研项目的突破性难题。

## 核心架构

系统采用四角色闭环架构：

| 角色 | 代号 | 核心职责 | 温度参数 |
|------|------|----------|----------|
| **正方构建者** | MX1 | 提出初始方案、逐条回应质疑、迭代修正逻辑链 | 0.1~0.2 |
| **反方批判者** | MX2 | 寻找逻辑漏洞、反例、风险点、边界条件 | 0.2~0.3 |
| **无限发散者** | MX3 | 生成所有可能性、极端假设、跨界联想 | 1.8~2.0 |
| **主审收敛者** | MX0 | 全链路质量评估、终止判断、生成最终报告 | 0.1 |

### 设计哲学

1. **能力绝对分离** — 发散思维与逻辑判断彻底切割，各角色严格在自己的温度区间内运行
2. **异质对抗优先** — MX1 与 MX2 必须使用不同厂商、参数规模相近的模型，确保对抗的有效性
3. **最小干预原则** — 避免过度工程化的格式强制与流程控制，充分利用模型自然语言理解能力
4. **可追溯性至上** — 完整记录每一轮每个模型的所有输出，支持任意节点回溯与重启

## 运行流程

```
项目初始化 → 前置准备 → 对抗-发散循环（核心引擎）→ 最终收敛与交付
```

### 对抗-发散循环

每一轮循环严格按照以下顺序执行：

1. **MX1 构建** — 基于主目标 + 历史对话 + MX3 发散结果，构造修正方案
2. **MX3 发散** — 并行生成大量发散点（默认 10 次 × 20~30 条），不做任何可行性判断
3. **MX2 批判** — 对 MX3 的每条发散点给出明确回应，找出 MX1 方案中的逻辑漏洞
4. **MX0 评估**（每 6 轮）— 质量评分 + 终止判断

### 终止条件

- 质量评分连续 3 轮 ≥ 90 分
- MX2 无法提出任何新的实质性质疑
- 达到用户设定的最大迭代轮次
- 用户手动终止

## 核心功能

- **多模型统一接入层** — 支持 OpenAI、Anthropic、DeepSeek、讯飞星火等主流大模型 API
- **项目管理与 RAG 知识库** — 项目级隔离、文件导入（Markdown/PDF/Word/代码）、向量化混合检索
- **对抗循环引擎** — 可配置工作流、自动上下文管理、断点续传、实时状态监控
- **TUI 终端界面** — 基于 Textual 构建，左侧项目列表、中间对话区、右侧信息面板
- **Web 界面** — 内置 Web 服务器，支持浏览器操作
- **完整数据日志** — API 请求/响应全记录、Token 消耗统计、成本预估

## 技术栈

- **语言**: Python 3
- **界面**: Textual（TUI）+ FastAPI / HTML（Web）
- **文档处理**: Markdown / PDF / Word 解析
- **向量检索**: 混合检索（关键词 + 语义）

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动 TUI 界面
python main.py

# 启动 Web 界面
python -m src.web.server
```

│   ├── tui/             # 终端界面（Textual）
